# Cloud Computing Concepts Reflection

Cloud computing has become an important part of my daily life because many of the applications I use depend on cloud technology. Three cloud services that I regularly use are Google Drive, Messenger, and Canva.

Google Drive is an example of **Software as a Service (SaaS)** because it allows users to store, manage, and share files through a web browser without installing or maintaining any servers. It uses the **Public Cloud** deployment model since anyone with a Google account can access the service over the internet.

Messenger is also classified as **Software as a Service (SaaS)** because it provides online messaging, voice calls, and video calls through the internet. It runs on Meta's cloud infrastructure, allowing users to communicate from different devices. Messenger is considered a **Public Cloud** service because it is available to the general public.

Canva is another **Software as a Service (SaaS)** application. It enables users to create presentations, posters, and graphic designs directly from a web browser without installing complex software. Canva is also deployed using the **Public Cloud**, making it accessible to millions of users worldwide.

Learning about Git and GitHub helped me understand why version control is important, especially in cloud computing projects. Cloud infrastructure often involves configuration files, scripts, and application code that are updated by multiple people. Without version control, it would be difficult to know who made changes or how to restore previous versions when problems occur.

Git allows developers to record every change made to a project, while GitHub provides an online platform where teams can collaborate efficiently. Team members can work on different features using branches, review changes before merging, and keep a complete history of the project. This reduces mistakes, prevents accidental loss of work, and makes collaboration more organized. As I continue studying cloud computing, I believe Git and GitHub will become essential tools for managing projects professionally and working effectively with a development team.
